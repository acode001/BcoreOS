# BcoreOS 🚀

> **彻底拉平测试与生产环境鸿沟，清除多发行版历史包袱；实现降低远程升级失败导致设备失联或不可启动的风险的“盲盒式”原子换代。**

本项目将**系统（引导/内核/驱动/库）与应用连续体**的打包结果定义为 **BcoreOS**。我们致力于讨论并落地不同 BcoreOS 之间的**跨版本用户数据继承、多节点批量差分原子更新、以及影子启动抗掉电安全机制**，最终**赋予个人与团体对整机全栈生态的完整绝对控制权**。

---
## 🔍BcoreOS实现原理
1. 为实现把未知的系统打包成可升级的BcoreOS并在升级后保持网络、数据不变，需要一个系统切换时可相互理解的公共层，本项目把该公共层定义为A服务系统（AOS）；
2. 系统启动时先启动AOS（与用户自行打包的BcoreOS有相同的内核二进制），启动后初始化网络磁盘后，切换BcoreOS系统；
3. 打包生成B1版本的BcoreOS系统携带配套的A1版本的AOS，升级时先把目标机器的AOS系统升级为A1版本，再由A1版本的AOS升级B1版本的BcoreOS；
